# 0.1.3 界面调整

目标：保留深色外观，将设置窗口改为符合 macOS 习惯的工具界面。

用户提供的旧版截图暴露出三个问题：大面积粗体和等宽字体、重复的说明文案、过多的彩色状态标签及嵌套面板。

## 调整

- 使用系统标题栏，默认进入菜单项；顶部只保留原生页面切换和收纳开关。
- 菜单项改为 SwiftUI Table，名称使用常规字重，显示方式使用原生下拉菜单。
- 通用设置和授权信息采用系统 Form，去掉概览指标、技术参数和重复说明。
- 保留深色系统背景，少量青色用于操作强调；不再用红色代表普通的“未启用”状态。
- 首次设置保留四个步骤，使用短标题、原生按钮和复选框；不再显示宣传语和功能卡片。
- “全部显示”同时暂停收纳，避免刚恢复就重新隐藏；重置之前增加确认。
- 预览模式的悬停和登录启动开关使用内存状态，不写入真实偏好或登录服务。
- 预览窗口标题和列表页脚明确标记示例数据，避免把界面样例误认为扫描结果。
- 再次打开应用时保留已有窗口和正在进行的设置流程。

## 平台依据

2026-09-10 核对 Apple 的 [Table](https://developer.apple.com/documentation/swiftui/table) 与 [Form](https://developer.apple.com/documentation/swiftui/form) 文档，采用系统组件的字体、排版和交互。Table 从 macOS 12 开始可用，满足当前 macOS 15+ 目标；没有引入第三方界面库。

截图用于验证界面与交互，使用安全预览数据和 SF Symbols。它们不是真实菜单栏扫描、收纳或点击的验收证据；真实功能记录见 runtime-qa.md。

## 0.1.11 托盘图标

- 第三方项目在可解析应用图标时优先显示原应用彩色图标；系统保留项继续显示捕获到的状态图标。
- 应用图标使用 28 pt，系统图标使用 22 pt；固定槽位增至 44 pt，点击高度增至 40 pt，面板高度增至 56 pt。
- 运行面板和安全预览共用内容宽度计算，包含项目间距、外边距、分隔线和重新收纳按钮。第一版截图暴露的最右图标裁切已通过修正后的中英文截图复查。
- 预览使用本机 macOS 自带应用图标验证原色渲染，不将这些样例伪装成真实扫描结果；设置页仍显示实际菜单栏截图，避免改变扫描状态的含义。

## 0.1.12 重新收纳操作

- 删除容易被误认为下载的 `arrow.down.to.line` 与孤立计数，改用 `arrow.uturn.backward.circle.fill` 表达返回收纳区。
- 托盘按钮直接显示本地化动作和数量；中文为“重新收纳 %d 项”，英文为 `Retuck: %d`。同一文案也用于辅助功能标签和通用设置页。
- 使用琥珀色填充与深色文字，将“收回临时显示项目”与青色常规操作、红色错误状态区分开。
- 按钮宽度固定为 114 pt，面板宽度公式同步增加对应操作区；计数和语言变化不会推动图标槽位，长文本仍保留单行缩放边界。

## 0.1.13 实机托盘一致性

- 实机截图暴露真实 `NSPanel` 会把 `.ultraThinMaterial` 渲染成厚重浅灰色，而安全预览被固定为深色。现在真实面板和内容视图统一使用 `darkAqua`，托盘本体改为确定的深色中性表面，不再依赖桌面材质颜色。
- 左侧图标改成带文字的状态区，中文显示“已收纳 N 项”，英文显示 `N Tucked`。正常状态、临时显示和重新收纳分别使用青色、状态圆点和琥珀色操作区。
- 应用图标从 28 pt 调整为 26 pt，系统图标从 22 pt 调整为 20 pt，槽位从 44 pt 调整为 40 pt，面板高度从 56 pt 调整为 50 pt。
- 面板宽度由统一布局策略计算，并给空状态和中英文文字预留固定空间。内容能放下时使用普通横排；只有超过屏幕可用宽度时才启用横向滚动，消除截图右侧的滚动控件残影。

## 0.1.14 显式应用布局

- “应用显示方式”从通用页移到菜单项页搜索栏右侧，使用带文字的青色主按钮；通用页删除同一操作，避免用户在“待收起”列表和执行入口之间来回切换。
- 选择“收起”只更新规则和待处理提示，完成配置后再统一应用。设置为“始终显示”的项目仍立即恢复，避免已隐藏项目无法找回。
- 主按钮在未启用收纳、没有待管理项目或布局事务进行中时禁用，避免重复提交相同布局。

## 0.1.15 图标与刷新稳定性

- 第三方应用优先显示外层应用自己的彩色图标；嵌套登录项不再直接显示 helper 名称或通用占位图标。旧式与新式 macOS 图标声明均参与解析。
- 输入法项目优先使用实际菜单栏截图；截图不可用时显示键盘符号，不再借用蓝色通用应用图标。
- 相同扫描结果复用现有行和图像实例，搜索、规则菜单、托盘图标与计数不会因为定时刷新重新创建视图。

## 0.1.25 深色布局

参考用户提供的 Mac 4 Breakfast 截图中深色工具面板的层次、蓝色选中状态和绿色成功提示，适配菜单栏收纳工作流。没有复制该软件的代码、品牌、电池数据或图片素材。

- 设置窗口默认 820 × 660 pt；品牌、版本、权限状态和收纳开关置于顶部，页面切换独立占一行。
- 背景使用中性石墨色；操作使用蓝色，成功使用绿色，收纳使用紫色，临时显示及重新收纳使用琥珀色。错误仍使用红色，并保留文字与符号，颜色不是唯一提示。
- 原生 Table 保留搜索、规则菜单和显式应用操作。应用图标放大到 28 pt 并保留原色，系统项目保留对应状态图标；来源名称置于第二行，状态列支持长英文换行。
- 通用与权限页采用无嵌套卡片的分区和分隔线，开关右对齐，停留时间保留原有 0.5–5 秒滑块。控件继续使用 SwiftUI Toggle、Picker、Slider 和 SF Symbols。
- 首次设置保留四步实际流程，中心显示应用图标或当前状态，底部提供上一步、步骤点和继续按钮。没有增加宣传页面。
- 2026-09-27 重新核对 Apple 官方 [Form](https://developer.apple.com/documentation/swiftui/form) 的平台信息（macOS 10.15 起可用）。沿用系统设置组件与已记录的 Table 依据；对齐与分区使用本地小组件适配，没有引入界面依赖。

截图为中英文安全预览；它们证明界面渲染，不代表真实菜单栏隐藏及多屏操作验收。macOS 15/26 仍需对应真机测试。
