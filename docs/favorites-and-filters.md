# 常用收藏与状态筛选

版本：0.1.29。目标是减少在较长项目列表中寻找常用应用的步骤。

## 交互

- 菜单项表格新增星标按钮。点亮设为常用，再次点击取消。
- 托盘将常用项目排在前面，并显示小星标。两组内部保持原顺序，通知数改变不会使图标跳动。
- 全部、常用、已收纳、临时显示四个分段筛选与文字搜索组合使用，数量跟随当前搜索。
- “已收纳”必须有真实隐藏状态；仅勾选收起、部分屏幕可见、待确认和临时展开都不计入。
- 无匹配结果时显示清除筛选按钮，一次恢复全部项目并清空搜索。

## 数据边界

收藏独立保存在本机偏好中，兼容已知旧项目标识；应用退出后仍保留收藏，不为暂时未运行的应用制造占位项目。重置菜单栏布局不会清除收藏。预览窗口里的星标操作只保留在内存，不修改用户偏好。

本功能不改变收纳规则、隐藏结果、系统菜单栏顺序、激活流程或轮询频率。不新增权限及网络请求。原有第三方菜单弹出、旧系统和扩展屏实机验收的限制仍以日常回归记录为准。

## 验证

自动化覆盖：收藏默认值、保存及清空、已知旧身份、丢失项目、稳定分区、通知变化、四种筛选、中文和英文搜索、空白和无结果、临时显示去重、刷新前后规则不变。使用独立偏好域和测试项目数据，不操作第三方应用。

界面验收：中英文设置窗口的收藏增减、筛选数量、组合搜索、空状态恢复和托盘星标；检查最小窗口宽度下是否遮挡或截断。
