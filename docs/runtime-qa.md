# 真实功能回归

日期：2026-09-10。整体状态：partial。

## 0.1.0 已授权安装版

- 环境：Apple Silicon，macOS 26.6.2，内置刘海屏与左侧扩展屏；iBar 未运行。
- 两项系统权限已由用户授予，真实应用界面与日志确认授权生效。没有修改 TCC 数据库或绕过授权。
- 已验证：真实窗口启动、双屏枚举、搜索匹配/无匹配/清空、刷新、悬停开关状态持久化、正常退出与再次启动。
- 图标采集有实际图像返回，但部分项目为空；不能把列表数量视为全部识别成功。
- 收纳测试失败：日志多次拒绝目标边缘在显示器外的移动，界面最终显示仍有项目未收纳。已停止重复移动，并关闭布局管理以便诊断；没有清除用户规则或登录启动设置。
- 发现本应用的跨屏镜像被加入待收纳列表；中文控制中心名称导致自身窗口 ID 发布失败；布局缩短分隔项的回调没有连接；主屏标签依赖焦点屏幕而非系统主显示器。

## 0.1.1 修复候选

代码调整：排除自身镜像、按稳定进程标识/自身标题解析窗口、接入分隔项布局生命周期、最宽屏幕有界尺寸、重新收纳等待分隔项尺寸更新、固定主屏身份、重新打开应用显示设置、首次显式录屏请求及进程内防重复。

- 自动化范围：36 项既有规则测试，17 项扫描/分隔项/权限策略检查。
- 回归证据：新增镜像扫描测试在旧扫描行为下失败，排除镜像后通过。
- 权限测试使用注入的系统调用替身，只验证调用策略，不代表 macOS 已实际授予新构建权限。
- UI 冒烟只验证八种预览窗口出现及最小尺寸，不验证点击、隐藏、恢复或文字无截断。
- 原有截图来自 0.1.0 安全预览，不作为 0.1.1 实机验收证据。
- 候选版已单独真实启动，确认 macOS 没有继承旧临时签名的辅助功能/录屏授权，界面显示两项待授权；因此未继续操作原菜单栏。随后退出候选版并重新打开原安装版。
- 本轮已运行：53 项测试通过，原有 36 项及新增 17 项分别在 AddressSanitizer 下通过，Debug/Release 构建通过，Debug 与 DMG 各八种预览窗口冒烟通过。
