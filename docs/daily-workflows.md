# 日常功能回归

每次交付区分规则测试、真实窗口事件、安装版交互和发行包验证。窗口能打开，不代表第三方菜单能点开；策略测试通过，不代表已在旧系统或扩展屏实测。

## 自动化检查

```bash
bash scripts/run-unit-tests.sh
bash scripts/run-refresh-tests.sh
bash scripts/run-panel-tests.sh
# 完成 Release 构建后：
bash scripts/run-ui-smoke-tests.sh work/DerivedData-Release/Build/Products/Release/MacBarTuck.app
```

`run-panel-tests.sh` 使用独立偏好和真实 AppKit 测试窗口，只向测试进程分发事件，不向桌面投递鼠标输入。覆盖左键按住、右键、同一应用其他窗口的外部点击、关闭动画期间重开和最终关闭。

## 逐项验收

| 流程 | 预期结果 |
| --- | --- |
| 启动、关闭设置窗口、重新打开、退出后再启动 | 没有重复进程，规则、语言、悬停时间和 Dock 选择保留 |
| 搜索中文、英文和不存在的名称，然后清空 | 数量随过滤更新，空状态可清除，原列表恢复 |
| 连续重新扫描 | 不重复项目，不移动已正确收纳的项目，不擅自重新收纳临时显示项 |
| 已收纳 A，再给 B 选择收起，然后刷新 | B 仍可见，规则保持待应用，点击应用后 B 才收起 |
| B 待应用时恢复 A | A 恢复，B 仍待应用，不连带隐藏 B |
| 开关收纳、全部显示、恢复最后一个收纳项目 | 真实菜单栏恢复，托盘不继续声称已隐藏 |
| 托盘左键、稍长按住再松开、右键 | 对应应用菜单或弹窗打开；按下时不会提前移除按钮 |
| 点击托盘背景、点击外部、连续开关 | 内部点击不误关，外部点击关闭，旧关闭回调不影响新打开的托盘 |
| 悬停开关、0.5/2/5 秒、提前离开、点击取消 | 延迟配置生效，短暂经过不展开，关闭后滑块禁用 |
| 中文和英文来回切换 | 页面、状态栏菜单、Dock 菜单和窗口标题同步 |
| Dock 显隐、登录启动 | 开关与系统实际状态一致，测试后恢复原值 |
| 四步首次引导、返回、完成 | 步骤与设置一致，完成后关闭引导 |
| 日志查看、导出、取消导出 | 导出存在且逐行是合法 JSON；取消不会生成文件 |
| 重置前取消、独立测试配置中确认重置 | 取消保留规则；确认恢复菜单栏并清除规则 |
| 主屏、扩展屏、拔插显示器 | 托盘位于操作屏内，收纳项目没有重复副本 |

## 2026-09-30 / 0.1.27

环境：Apple Silicon，macOS 27.0（26A428），Xcode 27.0。当前仅连接内置屏。

- 已验证：完整独立测试；刷新隔离、重复身份、隐藏失败、恢复最后一项和终止清理；日志轮换与 JSON；真实 AppKit 托盘事件；Release 构建；中英文共 16 个窗口启动冒烟场景。
- 两项缺陷均有针对性失败证据：刷新提前应用待收纳规则；托盘在内部 mouse-down 时关闭。修复后回归通过，包括刷新不提前应用、恢复其他应用不连带应用、明确点击应用才生效和快速重开。
- 安装版 0.1.26 已实测：启动和重新启动；中文搜索、无结果与清空；连续刷新；5 项临时显示重新收纳；权限状态展示；中文和英文切换；悬停时间 2→3→2 秒、关闭后滑块禁用；Dock 显示后隐藏；重置弹窗取消。已恢复测试前的语言、悬停和 Dock 选择。
- 新安装版最终交互、日志导出和登录启动切换尚待实机核验：继续测试时系统锁屏，原生工具拒绝操作。没有绕过锁屏或修改权限。
- 发行包与本机安装均为 0.1.27（29）、仅 arm64；DMG 完整性、SHA-256、临时签名以及安装版与包内可执行文件一致性均通过。旧版已备份，更新后的进程正常启动，但日志记录屏幕录制权限未生效，因此新版真实扫描、收纳和第三方菜单激活仍未验收；权限由用户配置。
- 本轮没有 macOS 15/26 真机和扩展屏；这些场景仅有策略及多屏数据回归，不标为真机通过。

## 2026-10-01 / 已授权安装版复测与 0.1.28 修复

环境仍为 macOS 27.0（26A428）、内置屏。实机安装版为 0.1.27（29），辅助功能和屏幕录制均显示已生效。

- 实机通过：13 项列表展示；钉钉通知数从 2 更新为 3 时仍保留应用名；选择钉钉收起后刷新仍为待收起，明确应用后变为已收起，再改为始终显示成功恢复；关闭与开启收纳状态同步；登录启动开关开→关→开；正常退出及进程重新启动。
- 实机通过：导出日志保存到指定本地目录，文件实际存在，1,685 行逐行通过 JSON 对象校验。诊断日志含本地运行信息，不纳入源码提交。
- 用户规则、中文界面、2 秒悬停、悬停开启、Dock 隐藏、登录启动开启和收纳开启均保留。测试中临时展开的项目已重新收纳。
- 实机发现并修复：微信 AX 标题为 `1` 时只显示数字；0.1.28 复用通知标题规则显示应用名加数量，覆盖中文、英文、`99+`、普通状态和无关应用数值。
- 实机发现并修复：打开收纳项的重试调用先刷新，刷新启动异步布局，紧接着再次激活会误报“菜单栏正在调整”。0.1.28 保留点击事务并等待布局结束，最多等待两秒；退出取消重试。故障注入用例在修复前失败，修复后通过，并覆盖布局不返回及等待期间退出。
- 尚未通过：Snipaste 左右键的第三方菜单弹出。事件派发成功并不能证明菜单已弹出；菜单栏自动化将其控件报告为屏外。腾讯柠檬打开时出现上述忙碌提示，不能标为完整激活成功。重启后状态菜单入口同样被自动化报告为屏外，未据此宣称状态菜单交互通过。
- 交付边界：0.1.28 提供源码与安装包，保留本机已授权的 0.1.27；新版安装后的实际第三方弹窗、旧系统及扩展屏验收仍未完成。首次引导完整交互和取消日志导出本轮没有补测，不以启动冒烟替代。
