MacOSBarTucK 0.1.32 安装说明

1. 将 MacOSBarTucK.app 拖入 Applications 文件夹。
2. 在“应用程序”中打开 MacOSBarTucK。
3. 按首次启动引导授予辅助功能和屏幕录制权限。
4. 若 macOS 提示应用来自未识别开发者，请在 Finder 中右键应用并选择“打开”。

从 MacBarTuck 升级时，先退出旧应用，再打开 MacOSBarTucK，勿同时运行。
原收纳规则和收藏会保留，确认新版正常后可移除旧应用文件。
若登录启动仍指向旧应用，在新版中关闭再打开“登录时打开”。

MacOSBarTucK 仅支持 Apple Silicon（arm64）和 macOS 15.0 或更高版本，包含 macOS 27 兼容路径。
请勿与 iBar、Bartender、Ice 等菜单栏整理工具同时运行。

当前开源构建使用临时签名，尚未经过 Apple 公证。

授权是否生效以窗口顶部及“权限与显示器”页为准。
若系统开关已经打开但这里仍显示“未生效”，先点“重新启动 MacOSBarTucK”。
仍未生效时，在两项系统权限中移除旧版本条目（可能名为 BarTuck、MacBarTuck 或 MacOSBarTucK），重新添加当前应用。
“定位当前应用”可以找到正在运行的那份程序，避免误授权到旧备份。

可在“通用 → 语言”中切换中文或 English，修改立即生效并在下次启动时保留。

设置菜单项时，先在“菜单项”页选择“自动 / 始终显示 / 收起”，再点击右上角“应用显示方式”。
逐项选择只保存规则，不会立即移动菜单栏；“通用”页不再提供重复的菜单项操作。

macOS 27 使用系统 Assessment Mode 按应用隐藏菜单栏项目，不再创建遮罩窗口或透明分隔项。
隐藏后由系统自动回收菜单栏位置，不应出现黑框或中间空槽。
MacOSBarTucK 自身入口以及控制中心、Wi-Fi、时钟、录屏/定位等系统安全项目会继续显示，不属于收纳失败。
关闭收纳、选择“全部显示”或退出应用会释放过滤状态并恢复菜单栏项目。

macOS 27 路径使用未公开的系统接口，适合开源侧载分发，不适合提交 Mac App Store。
