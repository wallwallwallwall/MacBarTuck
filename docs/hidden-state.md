## 0.1.7 修正

- 系统 Clock 是保留项，旧隐藏规则不会覆盖它；Wi-Fi 等其他可配置项保持原规则语义。
- 逻辑项目汇总各屏幕窗口的真实可见状态。仅全部已确认隐藏时标记已收起；一份可见则为部分可见；缺失窗口记录为待确认。
- 托盘不再依据期望规则提前加入项目。列表保留显示方式，并单独显示已收起、待收起、收起失败或待确认。
- 布局结束读回真实窗口，失败时不会宣称收纳成功，刷新仍为只读。
- 增加旧行为先失败的 Store 回归：一个仍可见但规则为收起的项目不能出现在托盘中。
